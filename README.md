## Common Mistakes to Avoid

Some codes explicitly state they cannot be combined with member rates or corporate codes. Always read the fine print on the specific code. If a code says "Not valid with member rates," it means you must choose one or the other—the member rate or the promo code—whichever gives a bigger discount. **Mistake 4: Applying Conflicting TopCashback Coupons**

TopCashback occasionally displays store-specific coupons or promo codes on their platform (like "Use code: SAVE15 for $15 off at Marriott"). Do not use these codes in addition to Marriott's official codes. Mixing them often voids the entire transaction for cashback purposes. Stick to Marriott's official promo codes and rely on TopCashback's baseline cashback rate.

**Mistake 5: Not Checking Expiration Dates or Property Restrictions**

Each code has specific parameters. GOF expires on August 28 for bookings and is valid through August 31 for stays at design properties only. If your dates or property don't match, the code won't apply. Always verify before entering payment information.
